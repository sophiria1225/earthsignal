# EarthSignal

地震・気象・SNS・市民観測をまとめ、利用可能な実測履歴と現在値の差を「異常度」として確認するアプリです。異常度は地震発生確率、危険度、予知結果ではありません。

## 現在のデータソース

- 地震: [P2P地震情報 API v2](https://www.p2pquake.net/develop/json_api_v2/)
- 気象・雲量・気圧: [Open-Meteo](https://open-meteo.com/en/docs)（現在値と過去30日の同時刻ベースライン）
- 公開SNS: Bluesky と Mastodon（サーバー側で収集、重複・過去談・否定文などを除外）。Blueskyはハンドル指定で自分の公開投稿も確認可能
- 市民観測: 音声信号、雲写真、構造化レポートをブラウザのローカルストレージへ保存
- 解説: `GEMINI_API_KEY` があれば Gemini、なければルールベース

取得できなかった項目に固定値やデモ値は補いません。履歴が足りないSNS・市民観測は「データ不足」として採点対象外にします。取得した現在値は45日間、このブラウザだけに1地域・1時間あたり1点で保存し、同時間帯の平常値との比較に使います。市民観測が現在値へ影響する期間は直近24時間で、音・雲の自己評価は同一地域で3件以上そろうまで総合値へ反映しません。事後検証タブの数値は、画面と分析形式を確認するための設計サンプルであり、研究結果ではありません。

## 起動

```bash
npm ci
cp .env.example .env
npm run dev
```

本番ビルドは `npm run build`、起動は `NODE_ENV=production npm start` です。ポートは `PORT`（既定値3000）で変更できます。

AI解説には安定版の `gemini-3.7-flash` を使用します。Blueskyの公開検索がホスティング元IPを拒否する場合は、Blueskyで発行したApp Passwordを `BLUESKY_IDENTIFIER` と `BLUESKY_APP_PASSWORD` に設定してください。認証情報はサーバー内のセッション作成だけに使い、ブラウザへ返しません。

## 実装上の境界

- ブラウザは外部APIへ直接アクセスせず、`/api/data/*` と `/api/social/*` の同一オリジンAPIを利用します。
- 外部APIにはタイムアウト、短時間キャッシュ、同時リクエスト統合を適用します。取得失敗時に前回表示を残しても、その古い値は現在の異常度へ再利用しません。
- Bluesky公開検索は語ごとに取得して重複排除し、否定文・過去談・比喩・既知の雷や工事・引用記事・公式発表後の反応を除外します。位置を本文から特定できない投稿は全国参考表示だけに残し、地域スコアへ加えません。
- AI解説APIは地域IDと寄与項目を許可リストで検証し、予知・危険度を示す生成文を破棄します。免責文はモデル出力に依存せずサーバー側で付与します。
- 端末データはJSONでバックアップ・復元・削除できます。保存不可の場合は画面に警告します。
- 画面表示中は5分ごとに更新し、オンライン復帰や2分以上離れていたタブへの復帰時にも再取得します。同時更新は1本へまとめます。

## プライバシーと制約

- SNS投稿者IDはサーバーで不可逆ハッシュ化し、表示用本文は24時間窓の一時抜粋だけを扱います。
- ハンドル指定のBluesky公開投稿確認はサーバーで5分間だけキャッシュし、端末の観測履歴には保存しません。
- 録音の生データと雲写真そのものは保存せず、端末内で算出した信号指標・利用者確認結果だけを保存します。
- 現在の市民観測は端末単位の非公開保存です。複数利用者を横断する集計、公開タイムライン、長期SNSベースラインには、同意・削除・不正投稿対策を備えた将来の永続ストレージが必要です。
- 緊急時は気象庁、自治体など公的機関の情報に従ってください。
